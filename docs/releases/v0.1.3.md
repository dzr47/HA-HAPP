# v0.1.3

## User interface

- Reorganized the VPN panel into four tabs: Overview, Devices, Servers and Routes.
- Added a compact Overview with the VPN policy, active router server and routing mode.
- Moved subscription management into the Servers tab and kept it available without crowding the main view.
- Added operation feedback for panel actions: starting, accepted, in progress, completed or failed, with elapsed time.
- Success messages describe confirmed outcomes. Selecting a server is explicitly distinguished from applying it; saving route lists is distinguished from applying them.
- Improved keyboard navigation and retained the selected tab while the panel refreshes.
- Added German, Spanish and Simplified Chinese translations for the new interface and feedback messages.

## Behaviour

The progress indicator reports the Home Assistant integration's operation state. It does not optimistically change the router's VPN state. A completed result is shown only after the integration reports completion; if completion cannot be confirmed, the panel asks the user to check the current state before retrying.
