# HA HAPP 0.1.1

Localization and registered-device discovery update.

## Changes

- The panel and setup flow now include German, Spanish and Simplified Chinese alongside English and Russian.
- The saved legacy default subscription name appears in the selected panel language without changing the stored source name or URL.
- The panel language selector and accessibility labels follow the selected language. Built-in status and error messages use the same translation catalogue.
- Samsung Galaxy A, M and S model numbers such as `A51` are recognized as phone search hints. Device search matches common Cyrillic and Latin transliterations.
- Entity names have translation keys for new Home Assistant installations. Existing entity names can remain as stored by Home Assistant.

## Compatibility

The same NetCraze/NDMS and XKeen/Xray requirements as 0.1.0 apply. Device classification is a UI search hint. It does not authorize a device or change its VPN policy. A registered offline device can be listed but needs a known local segment before VPN can be enabled.
