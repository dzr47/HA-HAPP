# v0.1.4

The Devices tab now has a router-wide VPN switch above the existing device-list control. The global switch has priority over the list and site-routing mode. Turning it off restores the saved NDMS default, segment and personal policies plus the previous Xray site rules; the selected VPN server is retained.

The operation creates protected HA and router-local backups, validates the Xray configuration and reads NDMS policies back before reporting success. Registered clients with an explicit permit rule receive the VPN policy even if no personal policy was previously displayed; unregistered clients inherit the router default. The integration rechecks new or changed clients during its normal poll and reports when the override is not confirmed.

The switch covers the existing NetCraze/XKeen transparent TCP and UDP path on supported IPv4 LAN segments. Local traffic and the connection needed to establish the VPN are excluded. A router with a different Xray layout or an uncovered LAN segment is rejected before changing routing.
