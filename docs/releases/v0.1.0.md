# HA HAPP 0.1.0

Initial public release of the Home Assistant integration for an existing NetCraze/XKeen/Xray setup.

## Included

- Home Assistant config flow, entities and administrator-only sidebar panel.
- Subscription import, VLESS REALITY node selection, router-side VPN checks and explicit server switch.
- Registered NDMS device selection, including offline registered devices.
- Site routing list import and the “VPN only for listed sites” mode.
- Router configuration backup and rollback for supported changes.

## Compatibility and limits

Developed for NetCraze NC-1812 / NDMS 5.1.7 with XKeen/Xray already installed through Entware and the documented Xray layout. Other router models, firmware versions and VPN engines are not supported by this release. Installation on a clean Home Assistant instance and live operation outside the original installation have not yet been verified.

Read the [compatibility and setup instructions](https://github.com/dzr47/HA-HAPP#readme) before installing. Do not replace a manually installed `netcraze_vpn` integration without backing up Home Assistant and the router first.
